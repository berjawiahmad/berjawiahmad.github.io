# Banana Run website V3 — Mystery hero teaser

This update adds a transparent-background, optimized `assets/heroes/mystery.webp` character and a distinct **WHO’S NEXT?** teaser card after the nine playable heroes.

## Deploy to GitHub Pages

1. Open your existing `berjawiahmad.github.io` repository on the **main** branch.
2. Upload the contents of this ZIP to the repository root, keeping the folder structure. Replace matching files when prompted.
3. **Keep the existing root `app-ads.txt` exactly as it is.** It is deliberately NOT included in this package.
4. Verify the homepage on desktop and mobile, the tenth teaser card, and the unchanged `https://berjawiahmad.github.io/app-ads.txt`.

The mystery character is a teaser for future content, not a currently playable tenth hero. No live GitHub files were changed automatically.
