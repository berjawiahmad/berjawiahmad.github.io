# Banana Run — GitHub Pages website

This is a static website intended for the **root** of the `berjawiahmad.github.io` repository.

## IMPORTANT: Preserve app-ads.txt

The ZIP intentionally **does not contain `app-ads.txt`**. Do not delete or overwrite the existing file in your repository. GitHub Pages must continue serving the existing file at `https://berjawiahmad.github.io/app-ads.txt` with exactly the same contents. Verify this URL after deployment. If GitHub Pages is deployed from a subfolder or a different branch, confirm the file remains in the published root.

## Deploy

1. Open the `berjawiahmad.github.io` repository on GitHub.
2. Back up the existing `app-ads.txt` and any other important files.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the published repository root. **Do not select “delete existing files” or force-push a replacement repository.**
4. In **Settings → Pages**, choose **Deploy from a branch**, your publishing branch (usually `main`), and `/ (root)` if needed.
5. Visit `https://berjawiahmad.github.io/` and `https://berjawiahmad.github.io/app-ads.txt` to verify both pages.

## Before public launch

- Replace the CSS/emoji concept illustration with approved Ninja/Mischief art.
- Replace gallery placeholders with actual gameplay screenshots.
- Add the verified Google Play listing URL and activate the download button.
- Add the verified support email, privacy-policy URL, and account-deletion URL. The support items are intentionally non-clickable until verified.
- Review any game feature claims and announcements before publishing.

No advertising file or publisher IDs are included in this package.
